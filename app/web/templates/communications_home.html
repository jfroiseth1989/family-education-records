Communications

Connect a mailbox to import educational-record emails in bulk, or use manual .eml upload (a later step) -- manual upload never requires a connected mailbox. FERChronos only ever reads mail from a connected account; it never modifies, moves, or deletes anything in your mailbox. There is no ongoing or background sync of any kind -- FERChronos only ever contacts Yahoo when you explicitly test a connection, browse/search a mailbox, or start/resume/retry an import. Disconnecting an account never deletes anything already imported -- every Communication, attachment, and Document it produced stays exactly as usable as before, offline included.

FERChronos never asks for, and will never accept, your normal Yahoo account password. Yahoo requires a separate app password for mail apps like this one:

  1. Sign in to Yahoo and go to Account Security.
  2. Find "Generate app password" (sometimes listed under "Other ways to sign in").
  3. Give it a label like "FERChronos" so you can recognize and revoke it later, independent of your real Yahoo password.
  4. Paste the generated password below -- not your normal Yahoo password.

This app password is saved only in this computer's own secure credential store (Windows Credential Manager, macOS Keychain, or your Linux keyring) -- never in FERChronos's database, never in a log file, and it is not shown again once you submit it.

Connecting only saves this credential securely -- it does not contact Yahoo, test the login, or import any mail. That happens later, only when you explicitly start an import. If this Yahoo address was connected here before, connecting again reactivates that same account rather than creating a separate one, so every message already imported through it stays correctly associated -- nothing is re-imported automatically.
