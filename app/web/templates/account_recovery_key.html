Recovery key

Your recovery key is the only way to reset your password if you forget it. FERChronos never stores or displays it again after it was first shown to you — only a secure verifier is kept, so even this application cannot show you your current key.

{% if recovery_key_updated_at %} Last generated: {{ recovery_key_updated_at }} {% else %} No recovery key has been generated for this account yet. {% endif %}

Generating a new key immediately invalidates the current one — if you have it written down somewhere, that copy will stop working. Losing both your password and your recovery key means there is no way back into this application; once whole-vault encryption is added in a future update, it will mean the vault's contents themselves become permanently unreadable.
